# Java Learning & Practice Repository

Welcome to my Java learning and practice repository! This space is dedicated to sharpening my Java programming skills, exploring core concepts, implementing data structures and algorithms, and building small projects.

---

## 📂 Repository Structure

The repository is organized into logical modules to make it easy to navigate through different topics:

*   **`basics/`**: Fundamental Java concepts (syntax, control flow, loops, methods, arrays).
*   **`oop/`**: Object-Oriented Programming principles (Classes, Objects, Inheritance, Polymorphism, Encapsulation, Interfaces).
*   **`collections/`**: Practice with the Java Collections Framework (`List`, `Set`, `Map`, `Queue`, etc.).
*   **`exceptions/`**: Exception handling and custom exceptions.
*   **`dsa/`**: Data Structures & Algorithms implementations (Sorting, Searching, Trees, Graphs).
*   **`projects/`**: Mini-projects and practical applications to reinforce learning.

---

## 🚀 Getting Started

To run or practice the code in this repository locally, follow these steps:

### Prerequisites
Make sure you have the following installed on your machine:
*   **Java Development Kit (JDK)** (version 17 or higher recommended). Verify installation using:
    ```bash
    java -version
    ```
*   A Java IDE such as **IntelliJ IDEA**, **Eclipse**, or **VS Code**.
